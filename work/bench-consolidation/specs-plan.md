# Bench consolidation spec plan

Build in this order after owner approval. File lists are likely touch points. Each slice keeps legacy readers and routes available until its replacement journeys pass. None requires restarting or replacing a live terminal during navigation. Run cargo fmt, clippy, Rust all-target tests and web unit tests for each slice. Web changes also require browser journeys at 1440 and 390 pixels.
