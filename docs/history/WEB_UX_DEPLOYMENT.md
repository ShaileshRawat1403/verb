# Remote deployment records

Records of deploying Verb Desktop to a specific host (paths, checksums, restarts, acceptance notes)
live in that host's private operations repository, not in this public one. For the owner's OnePlus
node that is `pocketfabric-node1`: `docs/deployments/` and `docs/runbook_verb.md`.

What stays here is product evidence: what the web UI does and how it was verified. See
`WEB_UX_JOURNEY_REVIEW.md`, `WEB_UX_PERFORMANCE_REVIEW.md` and `WEB_UX_POLISH_REVIEW.md`.
